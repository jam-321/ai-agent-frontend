# ai-agent-frontend

AI Agent 网页前端，技术栈为 Vue 3 和 Vite 6。

## 本地运行

```bash
npm install
npm run dev
```

环境脚本：

- `npm run dev`：development，`http://127.0.0.1:8081`
- `npm run test`：test，`http://127.0.0.1:8081`
- `npm run prod`：构建 production 包并本地预览，`http://127.0.0.1:8081`

开发与本地预览默认将 `/api` 代理到 `http://localhost:8080`。
